# Casamance Agriculture Pack

Agricultural knowledge for humanitarian workers assisting smallholder farmers in the Casamance region of Senegal, focusing on cassava, rice, maize, groundnut, and tomato crops.

## Contents

- **5 crops**: cassava, rice, maize, groundnut, tomato
- **15 diseases** with visual identification guides
- **31 treatment protocols** (organic and conventional)
- **12 pests** with identification and control methods
- **18 crop varieties** with local adaptation data
- **23 planting calendar** entries
- **12 months** of Casamance climate data
- **190 knowledge chunks** for semantic search

## Usage

Load this pack with FieldPack AI's offline field assistant.
The recommended edge model is `gemma-4-e2b-it`.
